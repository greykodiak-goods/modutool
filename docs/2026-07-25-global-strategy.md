# 글로벌 전략 마스터플랜 (2026-07-25, 대표 지시)

> 지시: ①글로벌 서비스 가능한 기능 우선 ②A-1(ThisIsMyVideo) 진행 ③광고·배너 수익화 전략 ④주요 언어팩 전부 지원(IP 등 체크) ⑤노출 전략.

---

## 1. ThisIsMyVideo — 글로벌 제품 기획 (이번 턴 착수)

**왜 글로벌 1순위인가**: 영상 도구는 언어 의존도가 가장 낮고(슬라이더·버튼 몇 개), 수요는 전 세계 공통("trim video online" 류는 영어권 검색량이 한국어의 수십 배). 업로드형 경쟁사의 약점(업로드 대기·워터마크·용량제한·프라이버시)을 온디바이스 FFmpeg가 전부 뒤집는다.

**라인업 (우선순위순)**:
| # | 툴 | 글로벌 검색 수요 | 구현 |
|---|---|---|---|
| 1 | **video-trim** ✅이번 배포 | trim/cut video online — 최상 | 스트림 복사(무손실·즉시), 키프레임 정직 고지 |
| 2 | video-to-mp3 | video to mp3 — 최상급 | `-vn -c:a libmp3lame` 재인코딩 |
| 3 | video-to-gif | video to gif — 상 | 2-pass 팔레트(고품질), fps·폭 옵션 |
| 4 | video-compress | compress video — 상 | CRF 프리셋 3단(재인코딩, 진행률 표시 필수) |
| 5 | audio-trim | mp3 cutter/ringtone — 상 | 벨소리 프레이밍 |
| 6 | video-mute / audio-extract 등 | 중 | 후속 |

**기술 결정**: ffmpeg.wasm 0.12 싱글스레드 코어(31MB, MIT) 벤더 — GitHub Pages가 COOP/COEP 헤더를 못 넣어 멀티스레드 불가. **CF Pages 전환 시 헤더 설정으로 MT 코어(수 배 빠름) 업그레이드 가능** — CF 전환의 실질적 이유 하나 추가. 대용량은 브라우저 메모리 한계(데스크톱 1~2GB)를 페이지에 정직 고지.

## 2. 수익화 — 광고·배너 전략

**현재 인프라**: 전 툴 페이지에 상/하 광고 슬롯 이미 배선됨(`ads-config.js` 설정만으로 활성화, 승인 전엔 DOM 미점유 = CLS 안전). 프리미엄 회원은 광고 자동 제거(이미 구현).

**네트워크 전략 (지역 이원화)**:
- **글로벌**: Google AdSense (자동광고 OFF, 수동 슬롯만 — UX·정책 안전). 승인 후 Auto ads 실험은 A/B로.
- **한국**: 카카오 AdFit 병행(국내 CPM 보완). site.js가 이미 두 공급자 모두 지원.
- 트래픽 월 10만+ 도달 시: Ezoic/Mediavine급 미드티어 전환 검토(CPM 2~5배). 그 전엔 AdSense가 정답.

**배치 전략 (이미 슬롯 있는 위치 기준)**:
1. 툴 카드 바로 아래(top 슬롯) — 작업 완료 직후 시선 경로. 최고 성과 예상 지점.
2. 가이드 본문 아래(bottom 슬롯) — SEO 유입 독자용.
3. (추가 예정) 결과 다운로드 완료 메시지 옆 네이티브 스타일 1개 — **작업 흐름 방해 금지 원칙**: 처리 버튼과 광고 사이 거리 유지, 오클릭 유도 배치는 정책 위반+신뢰 훼손이라 금지.
4. 영상 툴은 처리 대기시간이 있는 유일한 카테고리 → 처리 중 대기 화면이 자연스러운 노출 지점(정책상 '로딩 중 광고'는 라벨 명확히).

**전제조건(변동 없음)**: 도메인 구매 → AdSense/AdFit 신청(승인 2~4주가 크리티컬 패스). **애드센스는 서브패스별 승인이 아니라 도메인 단위 — thisismypdf.com 하나로 시작해도 전 서브사이트 커버 가능하도록, 도메인 1개만 먼저 사서 신청부터 거는 것도 옵션.**

**수익 손익분기 감각**: 페이지 RPM $2~8(도구 사이트 평균). 일 1만 PV 도달 시 월 $600~2,400. 목표 경로: 색인 → 롱테일 유입 → 링크 획득.

## 3. 다국어 — "주요 언어팩 전부" 로드맵

**원칙(재확인)**: IP 기반 강제 리다이렉트는 구글이 클로킹으로 오인할 수 있는 SEO 안티패턴(구글봇은 미국 IP). 대신:
1. **hreflang로 언어별 정본 URL 선언**(이미 ko/en 가동) — 검색엔진이 사용자 언어에 맞는 버전을 노출.
2. **브라우저 언어 감지 제안 배너**(이미 가동) — IP보다 정확한 사용자 의도 신호. 언어 추가 시 배너가 다국어로 확장.
3. 선택 기억(localStorage) — 이미 가동.

**언어 우선순위 (시장 크기 × 경쟁도 × 번역 비용)**:
- **1차 (다음 배치)**: 🇯🇵 ja(검색문화 유사·고CPM), 🇪🇸 es(4.5억 화자·경쟁 낮음), 🇧🇷 pt-BR(도구 검색 초강세), 🇮🇩 id(모바일 폭발 성장)
- **2차**: fr, de(고CPM), hi(볼륨), vi, th
- **구조**: `/ja/` `/es/` 언어 디렉토리(현 `/ko/` 패턴 그대로 확장). site.js LANGS 테이블에 셸 문자열 추가. 페이지 번역은 에이전트 배치(ko 생산과 동일 파이프라인 — 1언어당 툴 34페이지, 검증 자동화 이미 존재).
- **순서 제안**: 도메인·애드센스 승인이 걸리는 동안 1차 4개 언어를 **video+image 카테고리부터**(언어 의존 최소·글로벌 수요 최대) 확장 → 성과 보고 전체 확장.
- 계산기 일부(평수·만나이 등 한국 특화)는 글로벌판에서 제외하거나 현지화 대체(만나이→age, 평수→㎡↔ft²).

## 4. 글로벌 노출 전략

**SEO (기본기 — 유입의 80%)**:
1. 도메인 확보 즉시: Google Search Console + Bing Webmaster + (한국) 네이버 서치어드바이저 등록, sitemap index 제출. Bing은 글로벌에서 무시 못 함(DuckDuckGo·Copilot 유입 포함).
2. 언어별 hreflang 정본 구조(위 3번)가 그대로 국가별 노출 장치.
3. 롱테일 페이지 전략: 각 툴의 가이드+FAQ가 이미 롱테일 대응("how to trim video without watermark" 류). 언어팩 확장 = 롱테일 × 언어 수.
4. 프로그래매틱 확장(2단계): "X to Y" 변환 조합 페이지(mov-to-mp4 등)를 같은 엔진으로 생성 — 경쟁사들의 핵심 유입원.

**커뮤니티/제품 노출 (초기 스파이크 + 백링크)**:
1. **Product Hunt 런칭** — "privacy-first, no-upload tools" 앵글. 백링크+초기 트래픽. 도메인 확보 후 1회.
2. Reddit(r/InternetIsBeautiful, r/degoogle, r/privacy, r/DataHoarder) — 프라이버시 앵글이 정확히 먹히는 커뮤니티. 셀프홍보 규칙 준수(참여 이력 쌓고 소개).
3. Hacker News Show HN — "FFmpeg/OpenCV in the browser, nothing uploaded" 기술 앵글.
4. 한국: 클리앙·뽐뿌 팁게시판, 네이버 블로그/카페 리뷰 유도.
5. 무료도구 디렉토리 등재: AlternativeTo, ToolFinder류 — 백링크 확보.

**신뢰 자산**:
- 오픈소스 고지 페이지(FFmpeg·OpenCV·pdf-lib 크레딧) — 커뮤니티 신뢰 + 라이선스 준수.
- "Why no upload?" 설명 페이지 — 링크 걸리는 콘텐츠.

**측정**: 자체 pageview 분석(가동 중)에 ref 도메인 수집 이미 포함 — 채널별 효과가 백오피스에서 바로 보임.
