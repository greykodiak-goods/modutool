# 클릭당 500원 이내 광고 채널 조사 + 자동화 가능성 (2026-08-12)

> 대표 지시: "클릭당 5백원 이내로 SaaS 등 웹사이트나 어플 홍보할 수 있는 배너 광고,
> 커뮤니티나 카페나 그런 목록이 있는지 조사해서 알려줘. 자동화 가능한지도 검토하자."

단가는 기억으로 쓰지 않고 검색으로 확인한 값만 적는다. 확인 못 한 건 **미공개**로 표기한다.
출처는 문서 끝에 모았다. 광고 단가는 실시간 입찰이라 **모든 값은 시점·업종 의존**이다.

---

## 0. 먼저 — 조사 결과가 뒤집은 전제

조사하다 나온 산수 하나가 이 지시의 전제를 흔든다. 먼저 적는다.

우리 도구 사이트의 수익은 **1 PV당 ₩1~3**이다(RPM ₩1,000~3,000 ÷ 1,000PV, 앞선 `2026-07-26-revenue-plan.md`).
클릭을 ₩300에 사 오면, 그 방문자가 만드는 광고수익은 **₩1~3**이다.

> **무료 도구에 광고 트래픽을 사 오는 것은 구조적으로 100배 손실이다.**
> 단가를 얼마로 깎아도 이 부호는 바뀌지 않는다.

그러므로 유료 광고는 **무료 도구 유입용이 아니라, 값이 붙은 것을 팔 때만** 성립한다.

| 목적 | LTV | 허용 CAC | ₩300 CPC 기준 필요 전환율 | 판정 |
|---|---|---|---|---|
| 무료 도구 방문 (광고 수익) | ₩1~3 | ₩1~3 | — | **불가. 하면 안 된다** |
| 3층 폐쇄망 번들 B2B | ₩500,000~1,500,000 | ₩50,000~150,000 리드당 | 0.2~0.6% | **성립** |
| 2층 엔진 SaaS 구독 | (미정, 월 단위 반복) | 산정 후 판단 | — | 고객 검증 후 |

**결론 방향: 채널을 싸게 찾는 문제가 아니라, 광고를 어디에 쏠지 바꾸는 문제였다.**
그래도 지시하신 조사는 아래에 전부 마쳤다 — 어느 채널이 실제로 500원 이내가 되는지는
2층·3층 광고를 돌릴 때 그대로 필요한 정보다.

## 1. 클릭당 500원 이내 — 채널별 실측

### ① 가능 — 우리가 입찰가를 직접 정하는 채널

| 채널 | 도달면 | 확인된 단가 | 500원 이내 | 비고 |
|---|---|---|---|---|
| **카카오모먼트** (톡비즈보드·다음·카카오 지면) | 카카오톡/다음 | **CPC 최소 입찰 10원**, 기본값 500원, 1원 단위 입찰. 실시간 입찰이라 고정단가 아님 | **○ (입찰가를 우리가 정함)** | 국내 채널 중 하한이 가장 낮다 |
| **네이버 검색광고 (파워링크)** | 네이버 검색 | **최소 입찰 70원**, 평균 CPC 약 **530원**, 상위 3위 평균 **850원** | **△ → ○** 롱테일 키워드로 제한하면 가능 | 상위노출을 포기하면 500원 이내가 열린다 |
| **네이버 GFA** (성과형 디스플레이) | 네이버 지면 | 평균 **200~800원**, 기업/B2B **300~500원** | **○ (경계선)** | 배너 광고를 찾으신다면 국내에선 이게 정답에 가장 가깝다 |
| **Google Ads — 디스플레이** | 전 세계 웹/앱 | 검색보다 현저히 낮음(업종별 편차 큼, 시점 확인 필요) | **○** | 지면 품질 관리 필요(앱 지면 노이즈) |
| **Microsoft(Bing) Ads** | Bing/Edge | 통상 Google보다 낮음 | **○** | 국내 도달은 작다 |
| **Meta (FB/IG)** | 피드/릴스 | 업종·타깃 의존 | **△** | 소재 회전 비용이 큼 |

### ② 불가 또는 판단 불능

| 채널 | 확인된 사실 | 판정 |
|---|---|---|
| **Reddit Ads** | CPC **$0.75~2.00**(중위 $1.25~1.85). 최소 일예산 $5·총 $25 | **✗ ₩1,000~2,800 → 500원 초과** |
| **EthicalAds** (개발자 타깃) | **CPM 과금**, **최소 집행 $1,000**. 공개 참고치 CPM $2.25~2.75 | **도박이다.** 유효CPC = CPM ÷ (CTR×10). CTR 1%면 ₩350, 0.5%면 ₩700 → **CTR을 우리가 통제 못 하므로 500원을 보장할 수 없다.** 게다가 최소 $1,000이 1인 사업자에겐 실질 장벽 |
| **Carbon Ads** (개발자 타깃) | 광고주 단가 **미공개**(문의 필요) | 판단 보류 |
| **국내 커뮤니티 배너** (디시인사이드·클리앙·뽐뿌 등) | 광고 안내 페이지는 있으나 **단가 미공개, 개별 문의 · 정액제(기간제) 중심** | **CPC 보장 구조가 아니다.** 정액제는 클릭이 몇 번 나오든 같은 값을 내므로 "클릭당 500원 이내"는 사후에만 계산된다 → 첫 집행은 사실상 도박 |

> 커뮤니티 배너를 꼭 보시려면: 각 사이트 "광고 문의"로 **단가표 + 최근 CTR**을 요청해야 한다.
> CTR을 안 주는 곳은 유효 CPC를 계산할 수 없으니 집행하지 않는 게 맞다.

### ③ 클릭당 0원 — 조사 중 나온 가장 현실적인 답

광고비가 0이면 "클릭당 500원 이내" 조건은 자동으로 충족된다. 무시할 이유가 없다.

| 채널 | 성격 | 비용 |
|---|---|---|
| **디스콰이엇 (disquiet.io)** | 국내 IT 메이커 커뮤니티. 월 12만 메이커 방문 규모로 소개됨 | 무료 (별도 광고 크레딧 프로그램 존재) |
| **긱뉴스 Show GN** | 국내 개발자 뉴스. 자기 프로젝트 소개 게시판 | 무료 |
| **Sidedock** | AI·사이드프로젝트 발견 플랫폼 | 무료 |
| **Product Hunt / Hacker News Show HN / r/SideProject** | 해외 런치 채널 | 무료 |

**한계도 정확히 적는다**: 이건 **1회성 스파이크**다. 지속 트래픽이 아니다.
다만 우리에게 지금 필요한 건 지속 트래픽이 아니라 **2층·3층의 첫 고객 접점**이므로 성격이 맞는다.
(도구 40개를 한 번에 던지는 게 아니라, 사연이 있는 것 하나씩 — 예: "파일이 서버로 안 가는 PDF 도구" —
으로 나눠 올리는 게 이 채널들의 문법이다.)

## 2. 자동화 검토 — 되는 것과 되면 안 되는 것을 갈라 적는다

### 자동화 **가능** (공식 API가 있고 1인 광고주가 접근 가능)

| 채널 | API | 1인 사업자 접근성 | 판정 |
|---|---|---|---|
| **네이버 검색광고** | 공식 API (요청마다 **HMAC-SHA256 서명** 직접 생성) | **광고주 본인이 직접 신청 가능** | **★ 1순위.** 국내에서 완전 자동화가 실제로 열려 있는 유일한 채널 |
| **Google Ads** | Google Ads API. Basic Access는 test/production + 15,000 operation 한도 | developer token **Basic Access 신청** 필요. 2026-07-07부터 브랜드 검증 파일럿으로 심사가 수 시간까지 단축 | ○ (신청 필요) |
| **Meta Marketing API** | 앱 생성 + Marketing API 추가 시 **Standard access 즉시**(본인 소유 광고계정 대상, 쿼터 9,000점은 App Review 3~7영업일) | ○ | ○ |
| **Microsoft Advertising** | 공식 API | ○ | ○ |

### 자동화 **불가** (기술이 아니라 권한·계약의 문제)

| 대상 | 막히는 지점 |
|---|---|
| **카카오모먼트 API** | 조회·ON/OFF·일예산·입찰금액 변경까지 기능은 충분한데, **"카카오 광고 공식대행사와 사전 협의된 광고주"에게만 권한 부여**. 담당 마케터/채널 담당자를 통해 신청해야 함 → **소액 1인 광고주는 사실상 UI 수동 운영** |
| **국내 커뮤니티 배너** | 계약·소재 전달이 사람 대 사람. API 없음 |
| **네이버 GFA** | 프로그래매틱 접근이 제한적 |

### 자동화 **하지 않는다** — 명시적으로 금지선을 긋는다

**커뮤니티·카페 자동 게시/자동 댓글은 하지 않는다.** 기술적으로는 가능하지만:

1. 거의 모든 커뮤니티 이용약관 위반 → 계정·도메인 차단, 브랜드 손상
2. 앞선 기획의 사망 원인 1번(Google *scaled content abuse* 계열 리스크)과 같은 범주
3. **대표님이 처음에 주신 원칙 "남에게 피해를 주지 않는 선에서"에 정면으로 어긋난다**

커뮤니티 채널은 **사람이 직접, 낮은 빈도로, 읽을 가치가 있는 글로만** 쓴다.
여기서 자동화할 수 있는 건 게시가 아니라 **관측**이다 — 반응·유입·전환을 자동으로 모으는 것까지.

### 자동화의 진짜 알맹이 — 앞선 AutoOps 기획과 같은 문제다

광고 자동화에서 값이 나오는 지점은 소재를 많이 찍는 게 아니라 **끄고 켜는 판단**이다.

```
광고 API에서 비용·클릭 수집  →  우리 dailyStats(전환·실패)와 조인
        →  키워드/소재별 CPA 산출  →  기준 미달 자동 OFF · 초과달성 자동 증액
```

키워드 하나하나는 클릭이 하루 몇 건뿐이라 **개별로는 통계적 판단이 불가능하다.**
이건 `2026-08-12-autoops-grant-plan.md`의 **R1(극저빈도 신호 부분풀링 판정)과 완전히 동일한 문제**다.
즉 **광고 계정이 R1의 첫 실전 적용처**가 된다 — 연구과제와 마케팅이 같은 엔진을 쓴다.
지원서에 쓸 수치도 여기서 먼저 나온다.

## 3. 권고 — 우선순위 3단

**1순위 (이번 주, 비용 0원, 수동)**
디스콰이엇 · 긱뉴스 Show GN · Sidedock · Product Hunt / Show HN.
올릴 것은 도구 목록이 아니라 **"파일이 기기를 떠나지 않는다 + 외부 요청 0건 실측"** 한 가지 주장.
검증 가능한 주장 하나가 40개 나열보다 이 채널들에서 강하다.

**2순위 (소액 실험, 자동화 가능)**
네이버 검색광고 API로 **3층 B2B 구매의도 롱테일 키워드만**.
예: `폐쇄망 PDF 편집` `오프라인 PDF 합치기` `사내 PDF 도구` `망분리 이미지 편집`.
경쟁이 거의 없는 키워드대라 **70~200원**에 잡힐 가능성이 높고, 상위노출 경쟁을 피하므로
"클릭당 500원 이내" 조건도 만족한다. 일예산 ₩5,000~10,000으로 2주만 돌려 CPA를 본다.
지면 배너를 원하시면 같은 소액으로 **네이버 GFA(B2B 300~500원)**를 병행 테스트.

**3순위 — 하지 않을 것**
무료 도구 유입 목적의 유료 광고. 0절 산수 때문에 어떤 단가에서도 손실이다.
카카오모먼트는 단가 하한(10원)은 매력적이지만 **API가 막혀 있어 자동화 대상이 아니다** —
쓰더라도 수동 소액 실험으로만.
