# 도메인만 사서 자체 이메일 만들기 (2026-08-12)

> 대표 지시: "이메일 도메인만 사서 자체 이메일 만들려고 하는데 방법 있을지?"

---

## 0. 결론 — 됩니다. 도메인 값만 내면 이메일 비용은 0원입니다

다만 **"받기"와 "보내기"가 서로 다른 문제**라는 점이 함정이고, 대부분 여기서 막힙니다.

| | 받기 (수신) | 보내기 (발신) |
|---|---|---|
| 필요한 것 | 도메인의 MX 레코드 + 전달 서비스 | **별도 SMTP 경로 + 인증 레코드** |
| 무료로 되나 | **예, 완전 무료** | 예, 다만 설정이 하나 더 필요 |

---

## 1. 방법 3가지 비교

| 방법 | 비용 | 받기 | 보내기 | 사서함 | 적합 |
|---|---|---|---|---|---|
| **A. Cloudflare Email Routing + Gmail "다른 주소에서 보내기"** | **0원** (도메인값만) | ✅ **주소 무제한** 전달 | Gmail Send-As 설정 필요 | ❌ 없음 (기존 Gmail로 들어옴) | **우리 케이스 최적** |
| B. Zoho Mail 무료 | 0원 | ✅ 독립 사서함 | ✅ | ✅ | **웹메일 전용**(IMAP/POP 차단), 5명·5GB, 일부 리전만 |
| C. Google Workspace | 유료(계정당 월 단위) | ✅ | ✅ | ✅ | 캘린더·드라이브·문서까지 필요할 때 |
| D. 직접 메일서버 구축 | — | — | — | — | **하지 마십시오** (4절) |

### A를 권하는 이유

1. **도메인만 사면 끝난다.** 사서함 호스팅 비용이 0이다
2. **주소를 무제한으로 만들 수 있다** — `contact@` `support@` `biz@` `admin@` 을 용도별로 나눠 쓸 수 있다
3. **관리 포인트가 안 늘어난다.** 전부 기존 Gmail 한 곳으로 들어온다
4. **조건이 우리에게 이미 필요하다** — 도메인 네임서버를 Cloudflare로 옮겨야 하는데,
   **어차피 GitHub Pages에 커스텀 도메인을 붙이려면 DNS 관리가 필요하다.** 한 번에 해결된다

### B(Zoho)가 나은 경우

`@우리도메인`으로 **로그인하는 독립 사서함**이 꼭 필요할 때. 다만 무료 플랜은
**IMAP/POP이 막혀 있어 Outlook·Apple Mail 연결이 안 되고 웹메일로만 써야 한다.**
그게 걸리면 유료 Lite 등급(계정당 월 $1 수준)으로 풀린다.

---

## 2. ⚠️ 가장 흔한 함정 — Cloudflare는 **보내기를 안 한다**

> **Cloudflare Email Routing은 수신 전달 전용이다.**
> Gmail에서 그냥 답장하면 **`내계정@gmail.com`으로 나간다.** 상대에게 우리 도메인이 안 보인다.

해결: Gmail 설정 → **"다른 주소에서 메일 보내기(Send mail as)"** 에 `contact@우리도메인` 추가.
인증 메일이 Cloudflare 전달을 타고 Gmail로 들어오므로 확인 코드를 받을 수 있다.
발송 경로는 Gmail SMTP를 쓰거나, 대량 발송이면 별도 SMTP(Resend·Brevo·Mailgun 등)를 붙인다.

---

## 3. 반드시 해야 하는 DNS 레코드 3개 — 안 하면 스팸함으로 갑니다

| 레코드 | 역할 |
|---|---|
| **SPF** | 이 도메인 이름으로 메일을 보낼 수 있는 서버 목록 |
| **DKIM** | 메일에 서명을 붙여 위조를 막음 |
| **DMARC** | 위 둘이 실패했을 때 어떻게 처리할지 + 리포트 수신 |

**이건 선택이 아니다.** 2024년부터 Gmail·Yahoo가 발신자 인증을 요구하기 시작했고,
셋이 없으면 정상 메일도 스팸으로 분류된다.

> **특히 우리는 B2B 콜드메일 계획이 있다**(폐쇄망 번들 영업, `2026-07-26-revenue-plan.md`).
> 인증 없이 콜드메일을 보내면 **도메인 평판이 초기에 망가지고 복구가 오래 걸린다.**

---

## 4. 자체 메일서버 구축은 하지 마십시오

기술적으로는 가능하지만 1인이 감당할 일이 아니다:

1. **IP 평판** — 새 IP는 신뢰도가 0이라 보내는 메일이 대부분 스팸으로 간다. 회복에 몇 달
2. **대부분의 클라우드가 25번 포트를 막는다** (스팸 방지 정책)
3. **24시간 가동·보안 패치 부담** — 메일서버는 상시 공격 대상이다
4. **얻는 게 없다** — 위 A안이 0원인데 위험만 산다

**이건 "바퀴 재발명 금지" 원칙이 그대로 적용되는 자리다.**

---

## 5. 도메인 구매 시 주의

| 항목 | 권고 |
|---|---|
| **TLD 선택** | `.com` 우선. `.ai`는 연 등록비가 비싸다(somoon.ai가 그 예). `.io`·`.app`도 무난 |
| **등록대행사** | Cloudflare Registrar가 원가 판매라 가장 싸고 **whois 프라이버시가 기본 포함**. 단 `.kr`은 미지원 → `.kr`이 필요하면 가비아·후이즈 등 국내 등록기관 |
| **whois 개인정보** | **반드시 프라이버시 보호를 켠다.** 안 켜면 이름·주소·전화번호가 공개되고 스팸·사칭 대상이 된다 |
| **사이트와 같은 도메인을 쓸 것인가** | **같은 도메인 권장.** 브랜드 일관성 + 한 번의 구매로 이메일·사이트·Search Console이 전부 풀린다 |
| 자동 갱신 | **켠다.** 만료로 도메인을 잃으면 이메일과 사이트가 동시에 죽는다 |

---

## 6. 주소 설계 (우리 상황 기준)

| 주소 | 용도 |
|---|---|
| `contact@` | 사이트 문의 페이지 (`/contact/`는 이미 만들어져 있다) |
| `support@` | 사용자 문의·버그 신고 |
| `biz@` 또는 `sales@` | **B2B 영업·콜드메일 발신** |
| `admin@` | 도메인·서비스 관리 계정 등록용 |
| `no-reply@` | 시스템 발송 (수신 안 함) |
| 개인 주소 | 대표님 명의 |

**콜드메일 규모가 커지면 발신 도메인을 분리하는 게 정석이다**(메인 도메인 평판 보호).
지금처럼 수십 통 수준이면 같은 도메인으로 시작해도 되지만, 늘어나면 분리한다.

---

## 7. 순서 — 누가 무엇을 하나

### 대표님 (계정·결제라 제가 못 함)

1. 도메인 구매 (5절 기준)
2. Cloudflare 계정에 도메인 추가 → **네임서버 변경** (등록대행사에서 Cloudflare 것으로)
3. Cloudflare → **Email Routing 켜기** → 주소 만들고 목적지를 기존 Gmail로 지정
4. Gmail → 설정 → 계정 → **"다른 주소에서 메일 보내기"** 추가 + 인증
5. 도메인·Cloudflare 계정 정보를 안전한 곳에 보관 (**비밀번호는 제게 주지 마십시오**)

### 제가 할 것 (지시 주시면)

1. **SPF·DKIM·DMARC 레코드 값 작성** (그대로 붙여넣을 수 있는 형태로)
2. `/contact/`·`/ko/contact/`·About 페이지에 **새 이메일 주소 반영**
3. **GitHub Pages 커스텀 도메인 연결** (CNAME + DNS 레코드 + HTTPS 강제)
4. 사이트 전체 `__ORIGIN__` 교체, **기존 github.io → 새 도메인 301 정리** (색인 유실 방지)
5. **Search Console 도메인 속성** 등록 준비(DNS 인증), 네이버·Bing 동일 처리

---

## 8. 이 구매 하나가 동시에 푸는 것

도메인은 이메일만의 문제가 아니다. 지금 막혀 있는 것들이 한 번에 풀린다:

| 막힌 것 | 도메인이 생기면 |
|---|---|
| 자체 이메일 | ✅ 이 문서 |
| Search Console **도메인 속성** | ✅ (URL 접두어는 github.io로도 되지만 도메인 속성이 정본) |
| 브랜드 신뢰 (AdSense 심사, B2B 영업, 지원사업 서류) | ✅ `@gmail.com`으로 B2B 영업하면 신뢰가 깎인다 |
| 도메인 신뢰도 축적 시작 | ✅ 시간이 걸리는 일이라 **빨리 시작할수록 좋다** |

`2026-07-26-owner-checklist.md` ①번이 계속 미뤄져 있었는데, **이메일 때문에라도 지금이 적기다.**
