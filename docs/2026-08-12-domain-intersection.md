# 부동산·이커머스·CS 교집합에서 주제 다시 잡기 (2026-08-12)

> 대표 지시: "주제를 부동산이나 이커머스나 컴퓨터과학 분야로 하거나, 이것들을 융합해서
> 내가 좀 아는 부분으로 진행하고 싶어."

---

## 0. 먼저 — 세 번의 방향 전환이 말해주는 것

| 순서 | 주제 | 반려 이유 |
|---|---|---|
| 1 | A. 시공형 커머스 운영 AI | **지엽적, 시장 작음, 펜시하지 않음** |
| 2 | F1+F2. AI 거버넌스 | (확정했다가) **내가 아는 분야가 아님** |
| 3 | ← 지금 | |

두 요구가 서로 당기고 있다: **"내가 아는 분야"(당사자성)** vs **"크고 펜시한 시장"**.
지금까지는 둘 중 하나를 만족하면 다른 하나가 무너졌다.

> **그러니 이번에는 후보를 넓게 나열하지 않는다. 두 조건을 동시에 만족하는 교집합만 본다.**
> 그리고 각 도메인에서 **이미 남이 점유한 자리를 먼저 지운 뒤** 남는 자리를 본다.
> (F2에서 Dromo에, 이번 조사에서도 한 곳에 이미 선점당한 것을 확인했다. 순서를 바꾸면 시간을 버린다.)

## 1. 이미 점유된 자리 — 조사 결과 먼저 보고

### ⚠️ 부동산: "경매 권리분석 AI"는 이미 상품화되어 있고 가격도 바닥이다

| 사업자 | 내용 |
|---|---|
| **경매AI (newauction.kr)** | 사건번호만 넣으면 **등기부·매각물건명세서·전입세대열람을 자동 수집해 6개 항목 분석, 3분 내 리포트. 건당 1,900원부터** |
| **지지옥션** | 국내 경매정보 표준. 실시간 정보 + 통계 + **AI 낙찰가 예측** + 등기 서비스. **연 114만 7,000원** |
| **굿옥션** | 경매정보 서비스. **연 92만 6,000원** |
| ChatGPT 직접 활용 | 언론에서 "8만원짜리 유료분석 못잖다"는 실험 기사까지 나온 상태 |

**결론: 권리분석 AI를 주제로 잡으면 안 된다.** 기존 사업자 + 신규 스타트업 + 범용 LLM이
동시에 들어와 있고, **단가가 건당 1,900원까지 내려갔다.** 1인이 여기서 이길 방법이 없다.

**그런데 이 조사에서 훨씬 중요한 사실이 하나 나왔다:**

> **이 시장은 이미 연 92만~115만원짜리 구독료를 내는 시장이다.**
> 지불의사를 검증할 필요가 없다. 이미 증명돼 있다. 문제는 "무엇에" 내게 할 것인가다.

### 그리고 시장은 지금 커지고 있다 (확인된 수치)

| 항목 | 값 |
|---|---|
| 부동산 경매 신청 건수 | **2년 연속 11만 건 돌파** (2025년, 글로벌 금융위기 수준) |
| 서울 강제경매 소유권이전등기 신청 | 2026년 1~6월 **3,308건, 전년 동기 +42.5%** |
| 제주 법원 경매 진행 | 2026년 상반기 **4,644건, +27.2%** (역대 최대) |
| 서울 아파트 낙찰가율 | **102.9% — 3년 6개월 만에 최고** |
| 2026 전망 | 전문가들이 '매물 증가'와 '낙찰가율 상승'을 핵심 동향으로 꼽음 |

마지막 두 줄이 결정적이다. **낙찰가율이 102.9%면 "싸게 사서 남기는" 시대가 끝났다는 뜻이다.**
즉 **경쟁이 낙찰 전(권리분석)에서 낙찰 후(얼마나 잘 처리하는가)로 옮겨간다.**

## 2. 그래서 남는 자리 — 낙찰 **이후**가 비어 있다

권리분석은 **낙찰 전 5분**의 일이고, 이미 공짜에 가까워졌다.
낙찰자가 실제로 고통받는 건 **낙찰 후 6개월~1년**이다:

```
낙찰 → 잔금·경락대출 → 소유권이전 → 점유자 협상 → 인도명령·강제집행
     → 미납관리비·체납 정리 → 수선 → 임대/매도 세팅 → 세금 신고
```

이 구간의 특징:

1. **기한이 법으로 정해져 있고 놓치면 돈으로 물어낸다** (잔금 미납 시 보증금 몰수 등)
2. **협력사가 계속 끼어든다** — 법무사, 대출 상담사, 이사·명도 업체, 수선업체, 중개사, 세무사
3. **문서가 계속 쏟아진다** — 등기부, 매각허가결정, 배당표, 관리비 정산서, 견적서, 계약서
4. **그런데 관리 도구가 없다.** 지금은 **엑셀 + 카톡 + 기억**이다
5. **여러 건을 동시에 굴리면 즉시 통제 불능이 된다** — 전업 투자자는 항상 여러 건이다

> **여기가 비어 있는 이유는 어렵기 때문이 아니라, "정보 판매업"을 하는 기존 사업자의
> 사업 모델이 아니기 때문이다.** 지지옥션·굿옥션은 정보를 팔고, 낙찰 후엔 관여하지 않는다.

## 4. 추천 — **R1. 경매 낙찰 후 자산화 운영 AI**

### 4-1. 주제명 3안

1. **"낙찰 후 자산화 전 과정을 관리하는 부동산 경매 운영 AI"** ← 추천
2. "기한·협력사·문서를 자동 추적하는 경매 투자 운영 에이전트"
3. "여러 건을 동시에 굴리는 경매 투자자용 자산화 파이프라인 AI"

### 4-2. 왜 이게 대표님 영역인가 — 세 가지가 동시에 걸린다

| 대표님 자산 | R1에서의 역할 |
|---|---|
| **경매 시스템을 직접 구축** (`realestate-auction`) | 도메인 진입 비용 0. 물건·사건 데이터 구조를 이미 안다 |
| **`awning-ops`의 8단계 발주 상태 흐름 + 협력사 핸드오프** | **낙찰 후 프로세스가 구조적으로 동형이다.** 주문→자재→협력사→시공→정산이 낙찰→대출→법무사/명도업체→수선→임대로 대응한다. **이미 만들어 운영해본 구조를 옮기는 것** |
| **온디바이스 문서 처리** (40개 도구, 외부요청 0건 실측) | **등기부·전입세대열람에는 개인정보가 들어 있다.** 클라우드 업로드가 부담스러운 서류를 기기 안에서 처리한다 — 명분이 자연스럽다 |

세 번째가 특히 좋다. **개인정보가 든 서류를 다루는 서비스라 "안 올린다"가 기능이 아니라 신뢰의 근거**가 된다.

### 4-3. 무엇을 만드나 — 4개 모듈

| 모듈 | 내용 | AI가 필요한 이유 |
|---|---|---|
| **M1 기한 추적** | 잔금·이전등기·인도명령·신고 기한을 사건 단위로 자동 산출·알림 | 서류에서 날짜·조건을 읽어내야 한다 |
| **M2 문서 정리·요약** | 매각허가결정·배당표·관리비 정산서·견적서를 **기기 안에서** 파싱해 사건 타임라인에 자동 정리 | 서식이 제각각이라 규칙만으로 안 된다 |
| **M3 협력사 핸드오프** | 법무사·대출·명도·수선·중개 단계별 진행 상태와 견적 비교 | awning-ops의 협력사 확인 흐름을 그대로 이식 |
| **M4 실질 수익 집계** | 낙찰가 + 취득세 + 대출이자 + 명도비 + 수선비 + 미납관리비 → **실질 수익률**. 낙찰가율 102.9% 시대의 핵심 | 비용이 여러 문서에 흩어져 있다 |

**M4가 지금 시점의 핏이다.** 낙찰가율이 100%를 넘은 시장에서 투자자가 가장 두려운 건
"따고 보니 남는 게 없다"이고, 그걸 **낙찰 전에 시뮬레이션하고 낙찰 후에 실측**해주는 도구가 없다.

### 4-4. 지불의사 — 이미 증명돼 있다

| 근거 | 값 |
|---|---|
| 지지옥션 구독료 | **연 114.7만원** (월 13.1만원) |
| 굿옥션 구독료 | **연 92.6만원** (월 11.9만원) |
| 우리 제안 가격대 **[가정]** | 월 3~7만원 (정보 구독과 **병행**하는 운영 도구 포지션) |

**정보 사업자와 경쟁하지 않는다.** 그들은 "무엇을 살까", 우리는 "산 것을 어떻게 처리할까"다.
같은 지갑에서 나오지만 대체재가 아니라 **보완재**다 — 이게 영업에서 결정적으로 유리하다.

### 4-5. 경쟁 (실명으로, "없음" 금지)

| 경쟁자 | 강점 | 우리가 이기는 지점 |
|---|---|---|
| 지지옥션·굿옥션 | 데이터·브랜드·통계 | **낙찰 후는 그들의 사업 모델이 아니다** |
| 경매AI 등 분석 스타트업 | 저가 자동 권리분석 | 분석은 낙찰 전 5분. **우리는 그 후 6개월** |
| 엑셀 + 카톡 (실질 1위) | 무료·자유도 | 기한 누락을 **규칙이 막는다**, 여러 건 동시 통제 |
| 부동산 자산관리 앱 | 임대 관리 | **경매 특유 절차**(명도·배당·미납관리비)를 다루지 않는다 |

### 4-6. 정직한 약점 4개

1. **법률 영역 경계.** 인도명령·강제집행은 법률 행위다 → 제품은 **절차 관리·기한 알림·서류 준비**까지.
   판단은 법무사·변호사. **F1에서 세운 것과 같은 원칙**이고, 이 선을 넘으면 우리가 책임을 진다
2. **데이터 확보 비용.** 법원 공고는 공개지만 등기부·대장은 발급 비용이 든다
   → 우리는 **사용자가 이미 받은 서류를 처리**하는 방향(온디바이스)이라 데이터 재판매를 하지 않는다.
   이건 비용 회피이자 법적 안전이다
3. **시장이 경기 역행적이다.** 경매 물량은 침체기에 늘고 호황기에 줄어든다 → 매출이 경기와 반대로 흐른다.
   (**지금은 늘고 있다** — 그래서 타이밍은 맞다)
4. **전업 투자자 수가 제한적이다.** SAM은 이커머스보다 작다 → 그래서 단가를 낮추기보다
   **여러 건 운영하는 사람**을 정확히 겨냥한다

### 4-7. 왜 지금인가 (발표에서 쓸 한 문장)

> "경매 신청이 2년 연속 11만 건을 넘었고, 서울 강제경매는 올해 상반기에만 42.5% 늘었습니다.
> 그런데 서울 아파트 낙찰가율은 102.9%로 3년 6개월 만에 최고입니다.
> **물건은 늘고 마진은 사라졌습니다. 이제 승부는 낙찰 후에 납니다.**"

## 5. 대안 — R1이 막히면

**E1 (이커머스 채널 정산·손익 진실 검증)**: 시장이 R1보다 크고 당사자성도 최상급이지만
국내 셀러툴 경쟁이 두텁다. R1의 지불의사 검증이 실패하면 여기로 되돌아온다.
(이미 `2026-08-12-psst-topic-strategy.md`에 P·S·S·T 매핑이 있어 되돌리는 비용이 낮다.)

**C1 (온디바이스 문서 AI)**은 단독 사업으로 세우지 않고 R1·E1의 기술 축으로만 쓴다.
