# 신규 영역 확장 기획 — 기존 3개(PDF·이미지·계산기/유틸) 너머 (2026-07-25)

> 대표 지시: "3개 말고 더 다른 것들 기획해봐."
> 원칙 유지: 클라이언트 100% 처리(서버비 0·프라이버시 차별화)·상시 검색 수요·유지보수 최소.
> 이번에 검증된 무기: **opencv.js(13MB WASM)를 벤더링하면 컴퓨터비전급 기능도 온디바이스로 가능** — 배경/물체 제거로 실증. 같은 패턴으로 확장 여지가 크다.

## A. 신규 브랜드 후보 (경로형 → 도메인 분리 순서로)

### A-1. ThisIsMyVideo (/video) — 영상·오디오 도구 ★추천 1순위
- **엔진**: ffmpeg.wasm (MIT, ~25MB — opencv와 같은 "1회 다운로드 온디바이스" 패턴)
- **툴**: 영상 자르기(트림), 영상→GIF, 영상→MP3(음성 추출), 음성 자르기(벨소리), 영상 압축, 무음 구간 제거
- **왜**: "동영상 자르기", "mp4 mp3 변환" 검색량이 PDF급. 경쟁 사이트 대부분 업로드 방식이라 "업로드 없음" 차별화가 가장 크게 먹히는 영역(영상은 용량 커서 업로드가 진짜 고통). 광고 단가도 높은 편.
- **리스크**: 대용량 처리 시 메모리 — 길이 제한(예: 10분) 명시로 관리. 모바일 성능 편차.

### A-2. ThisIsMyScan (/scan) — 문서 스캔·OCR
- **엔진**: opencv.js(이미 벤더링됨 — 모서리 검출·원근 보정) + tesseract.js(Apache-2.0, 한국어 언어팩 ~15MB)
- **툴**: 사진→스캔 문서(모서리 자동 감지+원근 보정+선명화), 이미지→텍스트 추출(OCR), 스캔→검색 가능 PDF
- **왜**: "사진 스캔", "이미지 글자 추출" 상시 수요. 민감 문서(계약서·신분증)라 온디바이스 신뢰 소구 최강. opencv 재사용이라 한계비용 낮음.

### A-3. ThisIsMyName? (텍스트·문서 양식 콘텐츠 허브) — 툴이 아니라 콘텐츠 play
- 사직서·이력서·계약서·내용증명 등 **양식 템플릿 + 작성 가이드**(다운로드는 클라이언트 생성 docx/pdf)
- **왜**: 양식 검색은 한국 검색량 최상위 + 광고 단가 높음. 툴사이트와 내부링크 시너지(작성→PDF 변환→서명).
- **리스크**: 콘텐츠 제작 공수·법률 문구 정확성(면책 고지 필수). AdSense 승인엔 오히려 유리.

## B. 기존 브랜드 강화 (엔진 재사용 고효율)

| 후보 | 엔진 | 비고 |
|---|---|---|
| 이미지 업스케일(2배) | opencv.js resize+sharpen (진짜 AI 업스케일은 모델 필요 — v2) | "이미지 화질 개선" 수요 큼, 정직한 한계 고지 |
| 사진 자동 보정(밝기·대비·화이트밸런스) | opencv.js histogram | 원클릭, 수요 꾸준 |
| 증명사진 규격 크롭(3.5×4.5 등) + 배경 교체 | 기존 crop + bg-remove 조합 | 취준 시즌 수요, bg-remove와 원클릭 연결 |
| favicon 생성기(ico 멀티사이즈) | canvas | 개발자·자영업 수요 |
| PDF 텍스트 추출(.txt) | pdf.js(이미 있음) | 저비용 |
| 연봉 실수령액·퇴직금·연차 계산기 | 순수 계산 | 검색량 최상위(요율 연 1회 갱신 부담 명시) |

## C. 우선순위 제안 (수요 데이터 기반 의사결정)

1. **지금**: 방금 깐 pageview 분석으로 2~4주 카테고리별 실수요 확인 — 어느 영역이 실제로 크는지 보고 베팅.
2. **병행 가능(내 판단 착수 OK)**: B의 저비용 항목(증명사진·favicon·PDF 텍스트 추출·자동 보정) — 기존 엔진 재사용이라 리스크 0.
3. **대표 승인 후 착수**: A-1 ThisIsMyVideo(브랜드 신설 + 25MB 엔진 + 페이지 8종 규모), A-2 Scan(tesseract 언어팩 검증 필요), A-3 양식 허브(콘텐츠 방향성 결정 필요).
4. **도메인 구매 시**: 각 브랜드 경로(/video /scan)를 그대로 도메인으로 승격(이미 구조 준비됨).

## 이번 턴에 함께 배포되는 것 (지시 ②)
- **배경 제거(image-bg-remove)**: grabCut 온디바이스 — 사각형 드래그 → 자동 컷아웃 → 살리기/지우기 브러시 보정 → 투명 PNG/단색 배경. 픽셀 검증 통과(배경 α0·피사체 α255).
- **물체 제거(image-object-remove)**: TELEA 인페인팅 — 브러시 → 지우기 → 반복, 실행취소·원본 리셋. 비브러시 영역 원본 무손실. 픽셀 검증 통과.
- 공통: opencv.js 13MB 벤더(Apache-2.0), 툴 페이지에서만 지연 로드+캐시. "서버 AI 대비 한계" 정직 고지 포함.
