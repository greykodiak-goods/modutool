물체 지우개🔒 서버 업로드 없음

사람·글자·전선·잡동사니 위를 브러시로 칠하면 지워지고 주변으로 자연스럽게 채워집니다 — 전 과정이 내 기기에서 처리됩니다. 무료 — 설치·가입 없음.

🧽 이미지를 끌어다 놓거나 클릭해서 선택
한 번에 한 장 (JPG · PNG · WEBP) · 첫 사용 시 온디바이스 엔진(~13 MB)을 한 번 내려받습니다

지우고 싶은 부분을 브러시로 칠한 뒤(빨간 표시) 선택 영역 지우기를 누르세요. 다른 물체도 반복하면 됩니다.

사용 방법

  1. 사진을 위 영역에 끌어다 놓습니다. 첫 사용 시 온디바이스 엔진(~13 MB)을 한 번 내려받고, 이후에는 브라우저가 캐시합니다.
  2. 지우고 싶은 물체 위를 브러시로 칠합니다 — 그림자까지 빠짐없이 덮으세요. 빨간 표시가 지워질 영역입니다.
  3. 선택 영역 지우기를 누르면 그 영역이 주변으로 채워집니다. 다음 물체를 다시 칠하고 지우면 되고, 마지막 취소는 한 단계를 되돌립니다.
  4. 결과 다운로드를 누르면 편집본이 저장되고 원본 파일은 그대로 남습니다.

온디바이스 인페인팅 — 프라이빗하게, 한계는 솔직하게

물체 지우개 서비스는 보통 사진을 서버로 올려 AI 모델이 빈자리를 채웁니다. 이 도구는 고전적인 TELEA 인페인팅 알고리즘(OpenCV를 WebAssembly로 컴파일)을 브라우저 안에서 실행합니다. 칠한 영역은 주변 픽셀을 안쪽으로 번지게 해 복원되며, 그 과정에서 아무것도 전송되지 않습니다.

솔직한 기대치: 하늘·벽·잔디·피부·종이처럼 고르거나 부드러운 질감의 배경에서는 결과가 깔끔합니다. 복잡한 배경 위의 큰 물체는 서버 AI라면 피했을 얼룩이 남을 수 있습니다 — 잔상을 다시 칠해 가볍게 한 번 더 지우세요. 다시 계산되는 것은 칠한 영역뿐이고, 나머지 픽셀은 전부 원본 그대로입니다.

이런 때 좋아요

  • 여행 사진 속 관광객·행인
  • 거리의 전선·전봇대·쓰레기
  • 내 사진 위의 날짜 도장·워터마크 글자·로고
  • 인물 사진의 피부 잡티
  • 제품 사진에서 치우지 못한 물건

자주 묻는 질문

사진이 서버로 업로드되나요?

아니요. 컴퓨터 비전 엔진(OpenCV를 WebAssembly로 컴파일, 약 13 MB, 첫 사용 후 캐시)을 내려받아 지우기·채우기를 전부 브라우저 안에서 실행합니다. 사진은 기기를 떠나지 않습니다 — 그래서 가족사진이나 민감한 문서에도 안심하고 쓸 수 있습니다.

채우기는 어떻게 동작하고, 품질은 어느 정도인가요?

고전적인 TELEA 인페인팅 알고리즘을 사용합니다. 브러시로 칠한 영역을 주변 픽셀이 안쪽으로 부드럽게 번지듯 채우는 방식입니다. 전선·글자 도장·피부 잡티·잔디나 하늘 위의 행인처럼 비교적 고른 배경 위의 중소형 물체에는 아주 잘 작동합니다. 복잡한 배경 위의 큰 물체는 서버 기반 AI 인페인터가 더 자연스럽습니다 — 그 대신 여기서는 완전한 프라이버시를 얻습니다.

한 사진에서 여러 개를 지울 수 있나요?

네. 원하는 만큼 칠하고 지우기를 반복하세요 — 각 지우기 패스는 현재 결과 위에서 동작하므로 물체를 하나씩 차례로 지울 수 있습니다. 마지막 취소는 직전 패스를 되돌리고, 원본으로 되돌리기는 언제든 원본 사진으로 복귀합니다.

사진의 나머지 부분 화질이 떨어지나요?

아니요. 브러시로 칠한 영역만 다시 계산되고, 그 밖의 픽셀은 전부 원래 그대로 유지됩니다. 아주 큰 사진은 속도를 위해 약간 낮춘 작업 해상도로 처리하지만 이는 지워지는 영역 안에서만 적용되며, 손대지 않은 부분은 저장 시 원본 픽셀을 그대로 유지합니다.

정확히 어디까지 칠해야 하나요?

물체 전체를 그림자·윤곽선까지 포함해 살짝 여유를 두고 덮으세요. 흐릿한 잔상이 남으면 그 부분을 다시 칠하고 한 번 더 지우세요 — 진하게 한 번보다 가볍게 두 번이 대개 더 낫습니다.
